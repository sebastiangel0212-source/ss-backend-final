API de Autenticación del Proyecto S&S

1. REGISTRO DE USUARIO

Método: POST

URL: https://ss-backend-final.onrender.com/api/auth/register

Descripción: Registra un nuevo usuario en el sistema.

2. INICIO DE SESIÓN

Método: POST

URL: https://ss-backend-final.onrender.com/api/auth/login

Descripción: Autentica a un usuario con su username y password.
